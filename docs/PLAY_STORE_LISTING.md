## Full description

AgentFlow is a local-first AI workspace for reviewing and completing coding
tasks from Android. Connect an OpenAI-compatible model, select a workspace, and
let the agent inspect files, search code, propose changes, run approved commands,
and present evidence for review.

Key features:

- Review tool activity, command output, and file diffs.
- Approve sensitive actions before they run.
- Browse and edit workspace files with conflict detection.
- Inspect Git status, history, branches, and changes.
- Work with PDF and EPUB documents.
- Connect SSH runtimes and MCP tool servers.
- Keep workspace and conversation data locally by default.

AgentFlow does not include a model subscription. Users configure their own model
provider and are responsible for that provider's charges and terms. Remote
commands and code changes can affect user data; review approvals and diffs
carefully.
