# AgentFlow 轻量代码编辑器方案

## 定位

编辑器是 Android Coding Agent 的人工接管界面，不复制完整 VS Code。它与
Workspace、Runtime、Agent Diff、测试诊断共用同一套文件和状态模型。

## 开发阶段

### Editor MVP

- 从文件浏览器打开文本文件。
- 行号、等宽字体、多行编辑。
- 保存、撤销/重做、未保存状态。
- 保存前重新读取磁盘，检测 Agent 或外部程序造成的修改。
- 冲突时支持重新加载、覆盖或取消。
- Android 返回键离开前确认未保存内容。
- 限制超大文件和二进制文件。

### Coding UX

- 多标签页和最近文件。
- [已完成] 查找、替换、跳转行。
- 语言识别、缩进和基础语法高亮。
- 测试/编译诊断点击跳转到文件行列。
- Agent 修改后显示行级标记和 Diff。

### Advanced

- Tree-sitter 增量语法树和符号索引。
- LSP 诊断、补全、定义和引用。
- 用户缓冲区、磁盘版本和 Agent 修改的三方合并。

## 并发规则

1. 打开文件时保存基线内容。
2. 用户修改仅保存在编辑缓冲区。
3. 保存前重新读取 Runtime 中的文件。
4. 磁盘内容等于基线时允许保存。
5. 磁盘内容变化时禁止静默覆盖，并提示重新加载、覆盖或取消。
6. 保存后再次读取验证，并更新基线。

## Android 约束

- 所有文件访问通过 `Runtime`，兼容 Kotlin Bridge 和 Termux。
- 不依赖桌面文件 API 或 VS Code Server。
- 大文件采用上限保护；后续使用分块加载。
- App 进入后台前保留编辑缓冲区；第二阶段加入草稿持久化。
